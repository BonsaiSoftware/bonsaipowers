# owasp-security

A Claude Code skill encoding the **OWASP Top 10:2025** as actionable security patterns for React, Node.js, Azure, and cloud-native development.

## What this skill does

When activated, this skill guides AI coding agents to:

- **Detect** vulnerable code patterns matching OWASP Top 10 categories
- **Prevent** security flaws by applying secure alternatives during code generation
- **Review** existing code against 51 specific security rules with code examples
- **Configure** Azure cloud services and CI/CD pipelines securely

## Structure

```
owasp-security/
├── SKILL.md          # Activation layer — agent reads this first
├── README.md         # This file
├── metadata.json     # Skill metadata
├── references/
│   └── COMPILED-GUIDE.md  # Compiled full guide (auto-generated by build.sh)
├── rules/            # Individual rule files (51 total)
│   ├── _sections.md  # Category ordering and metadata
│   ├── _template.md  # Template for contributing new rules
│   ├── access-*.md   # A01:2025 Broken Access Control (8 rules)
│   ├── config-*.md   # A02:2025 Security Misconfiguration (5 rules)
│   ├── supply-*.md   # A03:2025 Software Supply Chain (5 rules)
│   ├── crypto-*.md   # A04:2025 Cryptographic Failures (4 rules)
│   ├── inject-*.md   # A05:2025 Injection (7 rules)
│   ├── design-*.md   # A06:2025 Insecure Design (3 rules)
│   ├── auth-*.md     # A07:2025 Authentication Failures (5 rules)
│   ├── integrity-*.md# A08:2025 Integrity Failures (4 rules)
│   ├── logging-*.md  # A09:2025 Logging & Alerting (4 rules)
│   └── error-*.md    # A10:2025 Exceptional Conditions (6 rules) — NEW in 2025
└── scripts/
    ├── build.sh      # Compiles rules/ → references/COMPILED-GUIDE.md
    └── validate.sh   # Validates rule file format
```

## Contributing

1. Copy `rules/_template.md` to `rules/<prefix>-<name>.md`
2. Use the correct prefix for the OWASP category
3. Include both vulnerable and secure code examples
4. Run `scripts/validate.sh` to check formatting
5. Run `scripts/build.sh` to regenerate AGENTS.md
